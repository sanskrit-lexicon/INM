## Символы

| Символ | Значение |
|---|---|
| **°** | сокращение слова. |
| **[ ]** | (1) заголовки, не встречающиеся в тексте как имена; (2) места текста, в которых синоним заменяет рассматриваемое имя; (3) поясняющие добавления. |
| **( )** | заголовки, встречающиеся в прозаическом замечании перед процитированным стихом. |
| **\*** | (1) благословение читателю; (2) заголовки, которые не являются или, возможно, не являются именами собственными. |
| **\*\*** | повторено. |
| **†** | в размере triṣṭubh (или jagatī). |
| **(†)** | в размере triṣṭubh (или jagatī), смешанном с çloka. |
| **††** | прозаический отрывок. |
| **(††)** | смешанные проза и çloka. |
| **>** | преемственность. |
| **⌐** | в браке с. |
| **&** | сражается против. |
| **+** | при содействии. |

Прописные буквы курсивом обозначают заголовок статьи, в которой они встречаются.

Номера стихов (обычным шрифтом) отсылают к Калькуттскому изданию.

Номера глав (**жирным шрифтом clarendon**) отсылают к Бомбейскому изданию, Çaka 1799.
